# yarfit-web

Website von **Yarfit** unter https://yarfit.de (GitHub Pages).

- `index.html` – Startseite
- `datenschutz.html` – Datenschutzerklärung (Quelle: `lib/core/legal/privacy_policy.dart` im App-Repo – bei Änderungen dort auch hier anpassen)
- `impressum.html` – Impressum
- `CNAME` – eigene Domain

Vor dem Store-Release: alle `[fehlt: …]`- und `[… ergänzen/prüfen]`-Stellen füllen und den Hinweis „Entwurf“ entfernen.
